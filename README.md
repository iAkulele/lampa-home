# Lampa Home

Плагин для Lampa 3.4.7: своя главная страница с подборками, каталоги с фильтрами, кнопка «Играть» (сама находит раздачу и запускает нужную серию), уведомления о новых сериях, «Скачать заранее» и экран «Скачанное».

## Скачать заранее и «Скачанное»

**«Скачать заранее»** — пункт в меню «…» на странице фильма или сериала. Плагин сам подбирает раздачу (по тем же правилам, что и «Играть»), отправляет её в TorrServer и просит скачать нужный файл целиком на диск ПК. Для сериала скачивается следующая непросмотренная серия. Пока идёт закачка, смотреть можно уже сейчас — но если скачать заранее, фильм потом не будет подтормаживать.

**«Скачанное»** — пункт в левом меню. Там все раздачи, отправленные на закачку:

- на карточке видно «Качается 45 %» или «Скачано» (обновляется раз в 5 секунд, пока экран открыт);
- OK — смотреть (без нового поиска, сразу с диска);
- долгое нажатие OK — «Удалить с диска?» → «Удалить»: раздача пропадает из TorrServer, её папка с кэшем стирается с диска. Для удаления нужен помощник на ПК (см. ниже).

Список «Скачанного» общий для всех устройств: он хранится в самом TorrServer (плагин помечает свои закачки в данных раздачи), поэтому фильм, отправленный на закачку с телевизора, виден и на телефоне, и на приставке, если у них указан тот же TorrServer. Удаление на одном устройстве убирает раздачу со всех. Если TorrServer недоступен, показывается последний список, сохранённый на этом устройстве, с подсказкой «TorrServer недоступен, показан локальный список».

### Настройки TorrServer для предзагрузки

Откройте веб-интерфейс TorrServer на ПК (`http://127.0.0.1:8090`) → «Настройки»:

1. **Кэш на диске** («Использовать диск» / UseDisk) — ВКЛ. Папка для кэша (TorrentsSavePath) — на диске, где есть место, например `E:\torrServer`.
2. **Размер кэша** — не меньше самого большого файла, который вы собираетесь скачивать заранее (для фильмов в 4K — 60–80 ГБ). Кэш считается для каждой раздачи отдельно: если файл больше кэша, скачается только его часть.
3. **Кэш предзагрузки** — 100 %.
4. **«Удалять кеш при удалении»** (RemoveCacheOnDrop) — ВЫКЛ. Иначе TorrServer сам сотрёт скачанное, как только раздача простоит без просмотра несколько секунд.
5. Сохраните настройки **до** того, как начнёте что-то скачивать: при сохранении TorrServer перезапускает все раздачи, и начатые закачки прерываются.

Плагин сам настройки TorrServer никогда не меняет.

### Помощник на ПК (для удаления)

TorrServer не умеет по команде с приставки удалить папку с кэшем, не меняя своих настроек. Поэтому рядом с TorrServer работает маленькая программа `helper/ts-clean.js` (Node.js 24, без установки пакетов). Как запустить и добавить в автозагрузку — пошагово в [helper/README.md](helper/README.md).

У помощника нет пароля, и он доступен всем устройствам домашней сети: используйте его только дома и не открывайте порт 8091 в интернет.

Адрес помощника задаётся в Lampa: Настройки → Lampa Home → «Адрес помощника на ПК» (по умолчанию `http://192.168.31.7:8091`).

## Разработка

- `npm test` — тесты.
- `npm run build` — собирает `lampa-home.js` (его и подключают в Lampa).
- `npm run serve` — стенд на `http://127.0.0.1:8099/`.
