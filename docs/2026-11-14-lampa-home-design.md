# Lampa Home — плагин «домашний экран как Netflix» для Lampa

Дата: 2026-11-14. Статус: черновик на утверждение.

## Зачем

Семья смотрит кино через Lampa на приставке Ugoos X3 (Android 9 AOSP, пульт + телефон с Zank Remote), проектор NOMVDIC P1000 (4K, HDR10/HLG, без Dolby Vision), звук в динамики проектора по HDMI. Торренты отдаёт TorrServer MatriX 150 на домашнем ПК (`192.168.31.7:8090`), поиск раздач — публичный JacRed (`jacred.xyz`), плеер — внешний Vimu.

Стандартная Lampa раздражает тремя вещами: главная забита чужими подборками и лишними пунктами меню; чтобы начать смотреть, надо пройти «Смотреть → список раздач → выбрать → плеер»; для сериалов и аниме не видно, сколько серий уже вышло и появилось ли что-то новое.

Плагин заменяет главный экран и меню, добавляет кнопку «Играть», которая сама выбирает раздачу и запускает Vimu, и показывает состояние сериалов. Пропуск заставок, YouTube и IPTV — вне проекта.

## Цели

1. Главная в стиле Netflix (вариант A из макетов): крупный баннер + горизонтальные ленты широких карточек 16:9.
2. Ленты в фиксированном порядке: **Новые фильмы → Новые ужасы → Аниме-онгоинги → Новые сериалы → Новые мультфильмы → Недавно просмотренное**.
3. Меню слева: только **Главная, Фильмы, Сериалы, Мультфильмы, Аниме** (плюс Настройки, которые Lampa не даёт убрать). Остальные пункты скрыты.
4. Каталоги Фильмы / Сериалы / Мультфильмы / Аниме с кнопками-фильтрами над сеткой (вариант A из макетов): **Жанр, Год, Сначала новые, По рейтингу**. В каталоге сериалов жанр «Ужасы» обязателен в списке жанров.
5. В лентах фильмов, ужасов и мультфильмов показываются только фильмы, уже вышедшие в цифре (по TMDB). Фильмы, которые идут только в кинотеатрах, не показываются. Аниме через этот фильтр не проходит.
6. На карточках сериалов и аниме — бейдж «вышло N из M серий» текущего сезона.
7. При запуске Lampa — уведомление, если у аниме, которое пользователь смотрел, вышла новая серия.
8. Кнопка **«Играть»** на карточке и на баннере: сама находит раздачу по правилам, отправляет на TorrServer и запускает Vimu с плейлистом с нужной серии. Если подходящей раздачи нет — открывает обычный список раздач Lampa.

## Не-цели

- Пропуск опенингов, эндингов, титров — не делаем (внешний плеер, Lampa им не управляет).
- YouTube, IPTV, онлайн-источники (Lampac) — не трогаем.
- Проверка наличия 1080p/4K раздачи для каждого фильма ленты — не делаем (сотни запросов к парсеру). Вместо этого фильтр по цифровому релизу TMDB.
- Пометка «4K» на карточках в лентах — не делаем по той же причине. Допустимо показывать её на карточке фильма после того, как парсер уже отвечал (кэш).
- Синхронизация между устройствами, аккаунты CUB — не трогаем, работает штатное.
- Поддержка Samsung/LG/веб: плагин должен не ломаться там, но целевое устройство — Android (Ugoos). Запуск Vimu есть только на Android.

## Анти-цели (что сделает проект провальным, даже если «работает»)

- Главная открывается дольше 3 секунд на Ugoos X3 из-за десятков запросов. Ленты должны рисоваться сразу из кэша, бейджи серий догружаться после.
- «Играть» выбирает экранку, Dolby Vision профиль 5 или оригинал без русской озвучки.
- Плагин ломает штатные экраны Lampa (поиск, карточка, настройки, список раздач) — они должны работать как раньше.
- После обновления Lampa плагин молча перестаёт работать и главная пустая. При ошибке — откат на штатную главную с уведомлением.

## Ограничения

- Lampa загружает плагины как один JS-файл по URL при старте. Хостинг: GitHub Pages в репозитории пользователя (аккаунт есть, `gh` доступен). Локально файл лежит в `I:\DISC\DEV\lampa-home\`, в репозиторий сайта euro-build-style ничего не пишется.
- Сборка Lampa на приставке — Android-приложение (версия уточнить на устройстве; ориентир — актуальная 2.x/3.x с новым плеером). Использовать только публичный API `Lampa.*` (Component, Activity, Api/TMDB, Storage, Favorite, Noty, Player, Torserver, Template, Lang, Select, Controller).
- Данные: TMDB через штатный прокси Lampa (`Lampa.TMDB`/`Lampa.Api`), чтобы не ловить блокировки. Раздачи — через настроенный в Lampa парсер (Jackett-совместимый JacRed), не напрямую.
- Интерфейс только на русском.
- Навигация — пульт (стрелки, OK, Back). Любой элемент должен быть достижим стрелками; мышь Zank — бонус, не основа.
- Внешний плеер Vimu: Lampa умеет передавать ему плейлист; позиция просмотра возвращается в Lampa не во всех версиях — прогресс-бар в «Недавно просмотренном» показываем, если Lampa знает позицию, иначе без него.

## Как это выглядит

### Главная (макет A)

- Вверху баннер на всю ширину: кадр (backdrop) фильма, название, строка «2026 · Триллер · ★ 7.4», 2–3 строки описания, кнопки **Играть** и **Подробнее**. На баннере — первый фильм из ленты «Новые фильмы» (моё решение; можно переключить на случайный из первых пяти в настройках плагина).
- Ленты: заголовок + «Все →» справа (переход в каталог с соответствующим предустановленным фильтром). Карточки 16:9 (backdrop), название внизу поверх картинки, при фокусе — увеличение и белая рамка.
- Бейджи на карточке: «7 из 12» (сериалы/аниме), прогресс-полоска (Недавно просмотренное).
- Уведомление о новой серии — штатный тост Lampa в углу при запуске, не блокирует навигацию. Не больше 3 тостов за запуск; остальные — в одном «и ещё N».

### Каталог (макет A)

- Заголовок «Фильмы» (или «Сериалы», «Мультфильмы», «Аниме»).
- Строка чипсов: **Жанр: …**, **Год: …**, **Сначала новые** / **По рейтингу** (переключатель). Нажатие на «Жанр» или «Год» открывает штатный `Lampa.Select` со списком. Выбранное подсвечено, «✕» сбрасывает.
- Ниже сетка широких карточек 16:9 (backdrop), таких же, как в лентах на главной: название внизу поверх кадра, рейтинг в углу. В макете были постеры 2:3 — это ошибка макета, пользователь попросил 16:9 везде. Бесконечная подгрузка страниц, как в штатных каталогах. Если у фильма нет backdrop в TMDB — подставлять постер с размытым фоном, чтобы сетка не ломалась.
- Переход по «Все →» с главной сразу ставит фильтр: из «Новые ужасы» — Жанр: Ужасы; из «Аниме-онгоинги» — каталог Аниме с сортировкой «Сначала новые».
- Фильтр запоминается на устройстве для каждого каталога отдельно.

### Карточка фильма / сериала

Штатная карточка Lampa, плагин добавляет первой кнопку **Играть** (и оставляет штатные «Смотреть», «Торренты», «Трейлеры» и т.д.). Для сериала «Играть» ведёт на следующую непросмотренную серию (по данным Lampa о просмотренном; если ничего нет — S1E1).

## Правила автовыбора раздачи («Играть»)

Вход: карточка TMDB (название, оригинальное название, год, тип, для сериала — сезон и серия). Запрос к парсеру — штатным способом Lampa (как «Торренты»), получаем список раздач с названием, размером, сидами, трекером.

Отсев (раздача выбрасывается, если):
- CAMRip, TS, TC, Telecine, Telesync, HDTS, «Line», экранка.
- Нет русской озвучки: в названии только Eng/Jap/Sub/субтитры/original и нет признаков русской дорожки (RUS, Rus, дубляж, Дубляж, многоголосый, MVO, DVO, LostFilm, HDRezka, Кубик, AniDub, AniLibria и т.п. — конкретный список слов оставляю строителю).
- Dolby Vision без HDR10-слоя: «DV» / «Dolby Vision» без «HDR10», «P8», «Profile 8», «HDR10+DV» рядом; профиль 5 — всегда вон.
- Для сериала: раздача не содержит нужную серию (одиночная серия другого номера или сезон не тот).
- Размер больше 60 ГБ для фильма — вон (Remux ради проектора не нужен).

Приоритет (сверху вниз, первый уровень, где есть кандидаты, выигрывает):
1. Качество: для фильмов/сериалов/мультфильмов 2160p → 1080p; для аниме 2160p → 1080p → 720p. 720p для не-аниме — только если ничего выше не нашлось вообще (тогда всё равно лучше, чем список).
2. Озвучка: сериалы и фильмы — LostFilm → HDRezka → любая русская. Аниме — AniDub → любая русская.
3. Звук: AC3 / AAC / EAC3 предпочтительнее DTS-HD / TrueHD (динамики проектора).
4. Сиды: больше лучше, но раздача с < 3 сидами проигрывает любой с ≥ 10 даже при худшей озвучке.
5. При равенстве — меньший размер.

Если после отсева пусто — открыть штатный список раздач с сообщением «Подходящей раздачи не нашёл, выберите вручную».

Выбранная раздача → TorrServer (штатно, с «сохранять в базу» по настройке Lampa) → Vimu с плейлистом: для сериала плейлист из всех серий раздачи, старт с нужной; для фильма — самый большой видеофайл.

Таймаут поиска — 12 секунд; пока ищет — штатный индикатор загрузки с текстом «Ищу раздачу…». Back отменяет.

## Данные для лент (TMDB)

- **Новые фильмы**: discover/movie, вышедшие в цифре (тип релиза Digital), дата цифрового релиза ≤ сегодня, сортировка по дате цифрового релиза убыв., язык ru-RU. Исключить мультфильмы (жанр 16) и документалки.
- **Новые ужасы**: то же + жанр 27.
- **Аниме-онгоинги**: discover/tv, жанр 16, страна JP (и/или keyword «anime»), статус «в эфире» (сериалы с эпизодом в последние 14 дней), сортировка по дате последнего эпизода.
- **Новые сериалы**: discover/tv, не аниме, с эпизодом в последние 30 дней, сортировка по дате первого эфира / популярности (точная формула — строителю, цель: свежие и живые сериалы наверху).
- **Новые мультфильмы**: discover/movie, жанр 16, не JP, вышедшие в цифре.
- **Недавно просмотренное**: штатная история Lampa (последние 20), новые сверху.
- Бейдж «N из M»: tv details → текущий сезон: число серий с датой ≤ сегодня / `episode_count` сезона. Один запрос на карточку, кэш на 12 часов в `Lampa.Storage`.
- Уведомление о новой серии: при старте для аниме из истории/избранного со статусом «в эфире» сравнить число вышедших серий с сохранённым; если больше — тост «Вышла N серия: Название»; сохранить новое число. Проверка не чаще раза в 6 часов.

Каталоги используют те же discover-запросы, плюс параметры жанра/года/сортировки из чипсов. «Сначала новые» = по дате релиза убыв., «По рейтингу» = vote_average убыв. с `vote_count ≥ 100`.

## Что решает строитель

- Конкретные вызовы API Lampa: как регистрировать компонент главной и каталогов, как подменить штатную главную, как скрыть пункты меню, как добавить кнопку в карточку, как вызвать парсер и TorrServer, как запустить Vimu с плейлистом. Ориентиры: исходники Lampa (yumata/lampa-source), плагины Airbagg/lampa-tv (autotorrent.js) и krajcik/lampa-plugins.
- Структура файла плагина (один файл; допустимы CSS в строке и шаблоны в строке).
- Схема кэширования и объёмы (ориентир: не более 200 КБ в Storage).
- Точный словарь признаков озвучки/качества в названиях раздач.
- Как тестировать без приставки: веб-сборка Lampa в браузере на ПК + плагин с локального http-сервера; финальная проверка на Ugoos.
- Процесс выкладки на GitHub Pages (репозиторий, ветка, адрес файла) и как Lampa на приставке подхватывает обновления (кэш-бастинг через `?v=`).
- Настройки плагина в «Настройки → Lampa Home»: включить/выключить баннер, стартовая лента, порядок лент — минимум; остальное зашито.

## Уточнения после проверки строителем (2026-11-14)

Решения ниже — мои, пользователь может переиграть любое.

- **Прогресс по сериям при внешнем плеере.** Lampa с Vimu может не знать, что серия досмотрена. Плагин ведёт своё хранилище: при запуске Vimu серия помечается как «начата», «следующая непросмотренная» = последняя запущенная + 1. Если Lampa сама вернула позицию/отметку — её данные приоритетнее. Это же хранилище — база для бейджей и уведомлений о новых сериях. Прогресс-бар в «Недавно просмотренном» — только если Lampa знает позицию.
- **«Ужасы» для сериалов.** У TMDB нет TV-жанра «Ужасы». В каталоге сериалов чипс «Ужасы» = фильтр по ключевым словам horror/zombie/vampire/haunted/slasher/supernatural horror (точный список — строителю) с запасным жанром Mystery (9648). Результат беднее, чем у фильмов, это принято.
- **Регион цифрового релиза.** `with_release_type=4` с `region=US`, сортировка `release_date.desc`. Русские дубляжи появляются через дни после US-digital; RU-регион после 2022 пустой.
- **Порядок онгоингов.** Сортировка по популярности при фильтре `air_date.gte = сегодня − 14 дней`; точную дату последнего эпизода не запрашиваем до отрисовки. Бейджи «N из M» догружаются после отрисовки, порядок карточек при этом не меняется.
- **Таксономия анимации.** Аниме = сериалы с жанром 16 и страной JP. Мультфильмы = полнометражки с жанром 16 любой страны (включая японские). Сериалы = все TV, кроме «Аниме» по определению выше (западная анимация вроде Arcane остаётся в Сериалах). Ленты и каталоги используют одни и те же определения.
- **Сиды против качества.** Штрафная оценка, не строгая лексикография: 2160p с < 3 сидами проигрывает 1080p с ≥ 10 сидами. Тот же порог применяется к озвучке. Итог: «мёртвый» вариант никогда не выбирается ради качества.
- **Сквозная нумерация аниме.** Если в названии раздачи нет `S0x`/«сезон», номер серии считаем сквозным; сквозной номер нужной серии вычисляем по TMDB как сумму серий предыдущих сезонов + номер в сезоне. Если не сошлось — откат в штатный список.
- **Макеты.** Выбранные варианты: `.superpowers/brainstorm/661-1794684463/content/home-style.html` (вариант A) и `catalog.html` (вариант A, но карточки должны быть 16:9, а не постеры). Пропорции: баннер ≈ 45% высоты экрана, в ленте 5–6 карточек в ряд на 1080p-интерфейсе.
- Ранее принятые мои решения: баннер = первый фильм ленты; тосты ≤ 3; лимит 60 ГБ; таймаут 12 с; 720p для не-аниме как последний резерв.

## Окружение (уточнено 2026-11-14)

- **Приставка:** Lampa 3.4.7 (веб-часть) внутри Android-клиента версии 1.13.6-586. По нумерации это клиент rootu (`top.rootu.lampa`, у него версии 1.12.x–1.13.x); проверить имя пакета на приставке перед сборкой. Клиент rootu умеет передавать Vimu плейлист и получать обратно позицию просмотра — строителю опираться на его мост (`Lampa.Android` / `AndroidJS`), штатный `Lampa.Player.play` с плейлистом как основной путь, прямой вызов моста как запасной.
- **ПК для разработки:** Lampa Desktop от GideonWhite1029 (<https://github.com/GideonWhite1029/lampa-desktop/releases>) уже установлен на этом ПК. Тестировать плагин сначала в нём (та же веб-часть Lampa), затем на Ugoos. В Desktop нет Vimu — ветку запуска плеера проверять только на приставке.
