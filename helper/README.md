# Помощник ts-clean

Маленькая программа для ПК, на котором работает TorrServer. Она нужна только для одного: когда вы в Lampa на экране «Скачанное» выбираете «Удалить», помощник убирает раздачу из TorrServer и стирает её папку с кэшем с диска.

Без помощника всё остальное работает: «Скачать заранее», экран «Скачанное», просмотр. Не получится только удаление — Lampa покажет «Помощник на ПК недоступен».

**Только для домашней сети.** У помощника нет пароля, и он слушает все сетевые адреса ПК (`0.0.0.0:8091`), чтобы до него достучалась приставка. Любое устройство в вашей сети может попросить его удалить скачанную раздачу. Не открывайте порт 8091 в интернет (не делайте проброс порта на роутере) и в Windows разрешайте доступ только для **частных** сетей.

Помощник удаляет **только** папки с именем из 40 символов (хэш раздачи) прямо внутри папки кэша TorrServer. Другие файлы и папки он не трогает. Настройки TorrServer он не меняет.

## Что нужно

- Node.js 24 (скачать с https://nodejs.org, кнопка «LTS», установить с настройками по умолчанию).
- TorrServer на этом же ПК, адрес `http://127.0.0.1:8090`, кэш на диске (см. корневой `README.md`, раздел про предзагрузку).

## Запуск вручную (проверить, что работает)

1. Скопируйте файл `ts-clean.js` в папку рядом с TorrServer, например `E:\TorrServer\ts-clean.js`.
2. Откройте эту папку в Проводнике, в адресной строке наберите `cmd` и нажмите Enter — откроется командная строка.
3. Введите `node ts-clean.js` и нажмите Enter. Должно появиться:
   `ts-clean listening on http://0.0.0.0:8091, TorrServer http://127.0.0.1:8090`
   и строка `TorrentsSavePath E:\torrServer` (ваш путь к кэшу).
4. Откройте в браузере `http://127.0.0.1:8091/status` — увидите список папок кэша и свободное место на диске.
5. Если Windows спросит про доступ к сети — разрешите для **частных** сетей (иначе приставка не достучится до ПК).

Окно командной строки закрывать нельзя — помощник работает, пока оно открыто. Для постоянной работы сделайте автозапуск.

## Автозапуск вместе с Windows

1. В папке с `ts-clean.js` создайте текстовый файл `ts-clean.cmd` с одной строкой:
   ```
   start "ts-clean" /min node "%~dp0ts-clean.js"
   ```
2. Нажмите `Win + R`, введите `shell:startup`, нажмите Enter — откроется папка «Автозагрузка».
3. Правой кнопкой по `ts-clean.cmd` → «Показать дополнительные параметры» → «Создать ярлык». Перетащите созданный ярлык в папку «Автозагрузка» (туда же, где лежит ярлык TorrServer, если он там есть).
4. Перезагрузите ПК и проверьте `http://127.0.0.1:8091/status` в браузере.

## Настройка в Lampa

Настройки → Lampa Home → «Адрес помощника на ПК». По умолчанию `http://192.168.31.7:8091`. Если у ПК другой адрес в домашней сети — впишите его, порт оставьте `8091`.

## Параметры (если нужно)

Переменные окружения перед запуском:

- `PORT` — порт помощника (по умолчанию `8091`);
- `TS_URL` — адрес TorrServer (по умолчанию `http://127.0.0.1:8090`).

## Как он устроен

- `GET /status` → `{save_path, free_bytes, folders: [{hash, bytes}]}`.
- `POST /delete` с телом `{"hash": "<40 символов>"}` → удаляет раздачу из списка TorrServer (`rem`), ждёт 2 секунды и стирает папку `<папка кэша>\<hash>`, если она ещё осталась. Ответ `{"ok": true, "deleted": true|false}` (`false` — папку уже убрал сам TorrServer или её не было).
- Папку кэша помощник каждый раз спрашивает у TorrServer, поэтому после смены пути в TorrServer его не нужно перезапускать.
